چیزهایی که معمولاً پرسیده می‌شود

بله، رایگان. کل پنل روی پلن رایگان Cloudflare Workers و دیتابیس D1 اجرا می‌شود و هیچ لایسنس پولی یا وابستگی به سرویس ثالثی وجود ندارد. تنها محدودیت‌ها همان سقف‌های پلن رایگان کلودفلر است — که در داشبورد پنل هم به‌صورت شفاف نمایش داده می‌شود.

یک حساب کلودفلر (حتی پلن رایگان) و یک اکانت تلگرام — همین دو تا. ربات تلگرام دیتابیس و Worker را روی حساب خودت می‌سازد و آدرس پنل را تحویل می‌دهد. نه دامنه می‌خری، نه سرور، نه چیزی نصب می‌کنی.

پنل لینک اشتراک را در پنج فرمت می‌سازد: base64 برای v2rayNG، Hiddify و Streisand؛ متن خام برای اپ‌های دیگر؛ و پروفایل JSON برای sing-box و Xray، به‌علاوه‌ی فرمت Clash. کاربر فقط لینک را در کلاینت خودش وارد می‌کند و بقیه‌اش خودکار انجام می‌شود.

ترافیک از لبه‌ی کلودفلر رد می‌شود و TLS آن با گواهی معتبر برقرار است. داده‌های پنل در دیتابیس D1 خودت ذخیره می‌شود و به هیچ سرور واسطی نمی‌رود. توکن API کلودفلر در مسیر ربات هم لاگ نمی‌شود و روی دیسک نوشته نمی‌شود — فقط از مسیر هم‌مبدأ به API کلودفلر فرستاده می‌شود.

تعداد کاربران خودت را تعیین می‌کنی؛ سقف عملی را بودجه‌ی درخواست روزانه‌ی پلن کلودفلر (۱۰۰ هزار درخواست) و منابع D1 تعیین می‌کند. برای هر کاربر می‌توانی حجم، تاریخ انقضا، تعداد درخواست و تعداد دستگاه هم‌زمان را جداگانه تنظیم کنی.

پشتیبان‌گیری کامل با خروجی JSON از بخش «پشتیبان‌گیری» پنل انجام می‌شود و می‌توانی همان را بعداً برگردانی. علاوه بر آن، ربات تلگرام هم می‌تواند پنل را به نسخه‌ی جدید آپدیت کند — بدون اینکه چیزی از تنظیماتت از بین برود.

پنلت را همین امروز بساز

کانال تلگرام Dev.Cop جایی است که نسخه‌های جدید، یادداشت‌های انتشار و راهنمای استفاده منتشر می‌شود. برای ساخت پنل، مستقیم با ربات حرف بزن — همه‌چیز از همان‌جا شروع می‌شود.
